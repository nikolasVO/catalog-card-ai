# Интерфейс: Orbs edition

## Изменения

Вместо большого рекламного заголовка используется компактное рабочее место.
Слева — примеры товаров и создание нового; в центре — поля или сырой JSON;
справа — результат с переключаемыми вкладками. На мобильном исходные данные
и результат переключаются, а не сжимаются в две узкие колонки.

Убраны фиолетовая палитра, декоративные градиенты, рекламные обещания,
многочисленные плашки и блок этапов процесса. Остались белая поверхность,
тёплый серый фон, тонкие границы и тёмная основная кнопка.

## Thinking Orbs

Ориентир: https://libraries.dev/orbs

На этой странице представлены индикаторы, а не готовый шаблон редактора.
В проекте используется адаптация открытого Canvas-движка `working/orbits`.
Это не подключение npm-пакета `thinking-orbs` и не React-обёртка.

Файл: `app/static/vendor/thinking-orbs.js`.
У upstream удалены TypeScript-типы; сохранены математика орбит,
проекция, распределение частиц, сортировка по глубине и пресеты 20/32/64.
Из общих функций оставлены только необходимые для одного состояния.
Добавлена локальная обёртка жизненного цикла: devicePixelRatio,
requestAnimationFrame, пауза при скрытии вкладки, reduced motion и cleanup.

## Состояния и сохранность результата

Изменение входных данных помечает ранее открытую карточку как устаревшую.
Готовый образец всегда относится к исходному примеру: если пользователь
изменил его данные, это явно обозначается. Ошибки API и буфера обмена
не уничтожают последнюю карточку. Строки из источника и модели экранируются.

Кнопка отмены прекращает ожидание в браузере через AbortController.
Это не обещание остановить уже начатую работу провайдера или избежать
списания: запрос мог быть получен сервером до отмены.

Данные не сохраняются в БД, localStorage или на сервере. Перезагрузка
и переключение товара могут сбросить несохранённые изменения; для
сохранения нужно экспортировать результат или скопировать входной JSON.

## Локальная сборка предпросмотра

`python scripts/build_preview.py` создаёт `preview.html` с теми же CSS/JS
и явно встроенными демонстрационными данными. Это не опубликованный сайт.
В автономном режиме генерация отключена с объяснением. Ни один пример
не выдаётся за ответ настоящего LLM API.

Запуск сервиса: прежняя команда `uvicorn app.main:app --reload`.
При реальном запуске из `app/templates/index.html` предпросмотровые фикстуры
не загружаются: форма обращается к существующим FastAPI-эндпоинтам.
