Как работать с карточкой

Выберите пример или добавьте товар. Заполните характеристики и описание, затем нажмите «Подготовить карточку».

Для настоящей генерации

По умолчанию используется локальная модель через Ollama, API-ключ не требуется. Запустите Ollama и загрузите модель, указанную в серверном файле .env. При необходимости можно выбрать облачный API и задать OPENAI_API_KEY в .env. Данные товара отправляются настроенной модели только по нажатию кнопки.

Образцы и экспорт

«Открыть готовый образец» показывает заранее подготовленную карточку исходного примера, а не ответ API. Образцы доступны без обращения к модели. JSON и Markdown скачиваются через «Экспорт».

Перед публикацией

Проверьте текст и недостающие поля. Пометка «данных нет» означает, что характеристику нужно уточнить, а не угадать.
