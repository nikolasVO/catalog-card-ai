# Сопроводительное сообщение

Здравствуйте! Выполнил тестовое задание на Python/FastAPI.

Разработал локальный сервис, который принимает данные контрольно-измерительного
прибора в JSON или веб-форме, формирует SEO-заголовок, описание, поисковые
запросы и коммерческий блок через API локальной модели Ollama. Для облачной
модели есть OpenAI-совместимый адаптер. Добавил экспорт в JSON/Markdown
и простой рабочий интерфейс.

Технические параметры переносятся из входного JSON без участия LLM.
Сгенерированный текст проверяется по формату, длине и техническим значениям;
при нехватке данных сервис сообщает, что нужно уточнить. Обрабатываются
ошибки API и некорректный JSON.

В исходном YML не было подробных технических характеристик, поэтому для двух
приборов подготовил входной JSON по публичным страницам и описал источники
параметров в `docs/SOURCES.md`. Редакторские примеры обозначены отдельно
от реальных ответов API. Добавлены автоматические проверки сервиса и интерфейса.

Ограничения MVP и идеи развития описаны в README и `docs/DECISIONS.md`.
Перед публикацией карточек требуется редакторская проверка.
